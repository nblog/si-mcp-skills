# 首版验收清单

建立日期：2026-11-19。状态：待验收。范围以[扫描设计](../notes/scan-design.md)、[实施方案](../notes/implementation-plan.md)和 ADR 0001/0002 为准。研究验证不能替代本清单。

2026-11-19 补充：研究预览版已完成安装态 E2E，见[Skill 安装态 E2E](skill-e2e-2026-11-19.md)。该记录只证明当前实现能复现既定样本结论；下列首版门槛仍需逐项执行，不得因 E2E 通过而整体勾选。

## Transport 与安全边界

- [ ] `verify-transport` 固定审阅路径/哈希、SDK 版本、协议/schema、工具目录和 structured response；拒绝任意工具、命令参数、提权和重试绕过。
- [ ] 超时、取消、预算耗尽、目标变化、权限拒绝和短读均有离线与授权实测记录；不把失败写成无发现。
- [ ] 报告和日志不包含原始内存 payload；敏感实测目标与授权范围可追溯。

## PE 与模块身份

- [ ] x86/x64 磁盘与映像布局、跨 4096 头/节表、稀疏目录、无导出、目录损坏和文件替换 fixture 通过。
- [ ] 磁盘基线配对使用可复验的文件哈希/版本与模块身份；路径同名、文件变化和基址重用被拒绝或标记。
- [ ] 模块前后复验、进程重名选择和重名模块基址消歧通过。

## Region diff 与 inline

- [ ] 磁盘可执行/运行时可执行交集、权限增减、不可读页、空洞和 65535 分块覆盖可从报告复算。
- [ ] 511/512 边界、跨块 patch、非入口 direct jump、返回补丁、既有指令操作数改动和普通重定位归一化通过。
- [ ] 无可信指令边界的差异保留 patch/unknown，不冒充 inline。

## EAT

- [ ] 有导出、无导出、目录一侧缺失、损坏、槽位改写、名称索引变化、转发字符串变化和空槽 fixture 通过。
- [ ] 授权实测样本中 EAT 目录、槽位、名称映射和转发范围均输出覆盖状态。

## IAT（首版必过）

- [ ] 名称导入、序号导入、32/64 位槽位、可信直达导出、多级转发、delay 冷状态和已解析状态通过。
- [ ] 目标 ApiSetMap 或可信 schema 解析 API set；不能仅凭全进程唯一同名导出宣称覆盖。
- [ ] 已知正确槽位、已知错误槽位、同一系统 DLL 内错误目标、转发循环、导出缺失和依赖不可信分别给出正确状态。
- [ ] IAT 阶段独立通过；不能用 EAT 或 inline 结果抵扣。

## 进程覆盖与交付

- [ ] 单模块与进程模式在同一固定输入上结果一致；指定模块/全部模块、共享预算、取消、失败隔离和 partial/gap 输出通过。
- [ ] x86/WOW64 与 x64 授权实测完成，跨环境依赖版本锁定。
- [ ] Typer CLI、PEP 723 依赖、Pydantic 配置、回放模式、报告 schema 和 `SKILL.md` 完成；安装或显式链接方式可复验。

## 记录规则

每次执行新增带 ISO 8601 日期的记录，写明目标架构、依赖版本、命令、样本、预期/实际结果和最小证据。只勾选已通过项；失败、部分和未执行分开记录。复验新增记录，不覆盖历史。
